# 🍔 麦门搭子 (McBuddy) — 多人拼单决策官

> 麦当劳 × WorkBuddy「1024 造物挑战 / 程序员创意开发大赛」参赛作品
> 基于 **麦当劳 MCP** 能力开发 · 用 [WorkBuddy](https://www.workbuddy.ai) 打造

## 这是什么
别人都在做「一个人怎么省钱」「一份套餐多少卡路里」。
**麦门搭子** 做一件没人认真做的事：**一群人怎么点最爽、又分得清账。**

朋友聚会、家庭出游、部门下午茶、情侣互点——把每个人的口味、预算、你手里快过期的券，
交给麦门搭子做一遍多人组合优化，输出：
- 每人「好吃又划算」的点单方案
- 公平分账表（谁该付多少，优惠怎么摊）
- 一张可一键转发群的 **「拼单战报」卡片**

## 为什么是我（赛道差异）
实时榜单 104 个项目，前排清一色是单人省钱 / 营养 / 比价。
多人拼单是**蓝海**，且「得叫上朋友一起用」天然带来传播——而本赛事按 GitHub Star 排名，传播力 = 排名力。

## 安装到 WorkBuddy
1. 打开 [open.mcd.cn/mcp](https://open.mcd.cn/mcp)，手机号登录 → 右上角「控制台」→ 「激活」领取 **MCP Token**。
2. 在 WorkBuddy 中：专家 → 技能 → 连接器 → 自定义连接器 → 添加 MCP，填入麦当劳 MCP 配置与你的 Token，保存并启用。
3. 把本仓库的 `SKILL.md` 作为 Skill 导入 WorkBuddy（或放置到 `~/.workbuddy/skills/mcd-buddy/`）。
4. 在对话里说：「帮我们 4 个人在麦当劳拼个单」，麦门搭子就开工了。

## 使用流程（五阶段，每步确认）
1. **组队**：收集人数、各自口味/忌口/预算、是否自取、必用券。
2. **拉数据**：通过麦当劳 MCP 只读接口取优惠券、账户积分、历史订单、菜单价格、地址。
3. **优化**：券按「快过期优先 + 匹配度」分配，求解每人最优方案与整单，算总节省与人均，出公平分账。
4. **确认**：表格复述完整方案，等用户确认。
5. **战报**：仅建单（付款由人完成），生成可分享战报卡片。

## 安全边界
- **只建单，不付款**：下单接口仅生成订单，支付必须由用户在麦当劳 App 内完成。
- 优先使用只读接口；写接口执行前必须向用户复述订单并获确认。
- 历史订单/账户数据仅用于本次拼单推理。
